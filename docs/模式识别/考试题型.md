# 考前梳理与预测

## 一、各章知识体系梳理

### 第1-3章：模式识别基础

| 知识点 | 核心内容 |
|--------|---------|
| 基本概念 | 模式、模式类、特征、特征向量、模型、学习（训练）、参数、超参数 |
| 与机器学习关系 | 模式识别 ≈ 机器学习的早期名称，核心都是"从数据中学习规律" |
| 基本流程 | 数据采集 → 特征提取/学习 → 模型学习 → 评估 → 部署 |
| 学习范式 | 监督学习（有标签）、无监督学习（无标签）、半监督学习（少量标签+大量无标签） |
| KNN 算法 | 原理：投票机制，找最近的 K 个邻居；K 值影响：太小→过拟合，太大→欠拟合；优缺点 |
| 系统框架 | 搞清问题 → 形式化假设 → 提出想法 → 形式化想法 → 从简单样例开始 → 解决问题 |
| "丑陋细节" | 数据清洗、缺失值、归一化、特征工程等工程实践中的繁琐问题 |

### 第4章：模型评估与选择

| 知识点 | 核心内容 |
|--------|---------|
| 误差体系 | 训练误差（训练集）、测试误差/泛化误差（测试集）、近似误差（模型能力上限） |
| 过拟合 vs 欠拟合 | 过拟合：训练误差小、测试误差大；欠拟合：两者都大 |
| 正则化 | L2 正则化系数是**超参数**，防止过拟合；增大正则化→抑制过拟合但可能欠拟合 |
| 数据集划分 | 训练集（训练参数）、验证集（选超参数）、测试集（仅最终评估） |
| K 折交叉验证 | K-1 折训练，1 折验证，重复 K 次取平均 |
| 混淆矩阵 | TP/FP/FN/TN → Accuracy、Precision、Recall、F1 |
| ROC/AUC | 按概率排序→逐阈值算 FPR/TPR→画曲线→计算 AUC |

### 第5章：PCA 主成分分析

| 知识点 | 核心内容 |
|--------|---------|
| 基本思想 | 降维 + 最大化保留方差（信息量） |
| 核心操作 | 对协方差矩阵做**特征值分解**，取特征值最大的 k 个特征向量 |
| 主成分选择 | 按特征值大小排序，特征值越大→方差越大→越优先 |
| 数据形状变化 | (n, d) → (n, k)，样本数不变，特征列减少 |
| PCA vs 特征选择 | PCA 是**特征提取**（构造新特征），不是特征选择（挑选旧特征） |
| 累计方差贡献率 | 前 k 个特征值之和 / 所有特征值之和，衡量保留了多少信息 |

### 第6章：Fisher 线性判别（FLD）

| 知识点 | 核心内容 |
|--------|---------|
| 核心目标 | **最大化类间离散度，最小化类内离散度** |
| 目标函数 | 广义瑞丽商 J(w) = (wᵀSʙw) / (wᵀSᴡw) |
| 散度矩阵 | Sʙ：类间离散度矩阵；Sᴡ：类内离散度矩阵 |
| 最优解 | Sʙw = λ Sᴡw（广义特征方程）；二分类：w = Sᴡ⁻¹(μ₁-μ₂) |
| FLD vs PCA | 核心区别：FLD **有监督**（用标签），PCA **无监督**（不用标签） |
| 关键性质 | J(w) 与 w 长度无关，只与**方向**有关 |

### 第7章：SVM 支持向量机

| 知识点 | 核心内容 |
|--------|---------|
| 核心思想 | **最大化分类间隔**（Margin） |
| 支持向量 | 距离超平面最近的样本点 |
| 硬间隔 | 要求严格线性可分：yᵢ(wᵀxᵢ+b) ≥ 1 |
| 软间隔 | 引入松弛变量 ξᵢ，允许少量误分类，处理近似线性可分 |
| 核函数 | 将数据隐式映射到高维空间，解决非线性问题（核技巧） |
| Mercer 条件 | 核矩阵必须**半正定** |
| 对偶问题 | 与原问题**等价**（强对偶性），推导步骤：拉格朗日→求导→回带 |
| SMO 算法 | 每次优化两个变量，子问题**存在闭式解** |
| 多分类 | OvO：C(k,2) 个分类器；OvA：k 个分类器（10类→45/10） |
| 解的性质 | **稀疏性**——只与支持向量有关 |

### 第8章：概率方法

| 知识点 | 核心内容 |
|--------|---------|
| 贝叶斯公式 | P(ωᵢ\|x) = P(x\|ωᵢ)P(ωᵢ) / P(x)，后验 = 似然×先验/证据 |
| 先验概率 P(ω) | 在观察到数据之前对类别的信念 |
| 类条件概率 P(x\|ω) | 在给定类别下观察到特定样本的概率 |
| 后验概率 P(ω\|x) | 观察到样本后，属于某类的概率 |
| MLE（最大似然） | 找参数使**观测到当前样本的概率最大**，参数是固定未知常数 |
| MAP（最大后验） | 找参数使**后验概率最大**，引入先验知识 |
| 贝叶斯估计 | 参数是随机变量，求参数的后验分布，对参数积分做预测 |
| 直方图估计（非参数） | 缺点：边界不连续、台阶状突变、bin 宽度敏感 |
| 核密度估计（非参数） | 优点：连续光滑；公式：f̂(x) = (1/nh) ΣK((x-xᵢ)/h) |

### 第9章：距离度量与回归

| 知识点 | 核心内容 |
|--------|---------|
| 向量范数 | L₁（曼哈顿）、L₂（欧氏）、L∞（最大绝对值）、马氏距离 |
| 余弦相似度 | 衡量方向相似度，与向量长度无关，适合文本等高维稀疏场景 |
| 幂平均 | 随 p 增大单调递增：p→-∞ 为 min，p=-1 调和，p=1 算术，p=2 平方，p→∞ 为 max |
| 线性回归 | 最小二乘法：min Σ(yᵢ-ŷᵢ)²，解析解 w = (XᵀX)⁻¹Xᵀy |
| 特征规范化 | Min-Max 缩放、Z-score 标准化、L₁/L₂ 规范化 |
| 激活函数 | Softmax（多分类概率）、Sigmoid（二分类）、Tanh（双曲正切） |

### 第10章：信息论与决策树

| 知识点 | 核心内容 |
|--------|---------|
| 熵 H(X) | 随机变量不确定性度量，均匀分布时最大 |
| 联合熵 H(X,Y) | 两个变量的总不确定性 |
| 条件熵 H(Y\|X) | 已知 X 时 Y 的**剩余不确定性** |
| 互信息 I(X;Y) | I(X;Y) = H(Y) - H(Y\|X)，衡量 X 对 Y 的信息量 |
| 相对熵/KL 散度 | 衡量两个分布的差异，≥0，不对称 |
| 交叉熵 | = H(p) + D_KL(p‖q)，最小化交叉熵 = 最小化 KL 散度 |
| 信息增益 | Gain(Y,X) = H(Y) - H(Y\|X)，ID3 的分裂依据 |
| ID3 决策树 | 选择信息增益最大的特征分裂；不能直接处理连续特征 |
| 霍夫曼编码 | 最优前缀码：高频→短编码，低频→长编码 |
| mRMR | 最大相关（与标签）、最小冗余（特征间） |

### 第15章：神经网络

| 知识点 | 核心内容 |
|--------|---------|
| 基础 | 神经元、激活函数、前向传播、损失函数 |
| BP 算法 | 链式法则反向传播误差梯度，更新各层权重 |
| CNN 架构 | 卷积层（特征提取）+ 池化层（降维）+ 全连接层（分类） |
| 关键参数 | 卷积核大小、填充、步幅、特征图尺寸计算 |
| 感受野 | 输出特征图上一点对应输入图像的区域大小 |
| VGG16 | 13层卷积（3×3小卷积核堆叠）+ 3层全连接，结构规整 |

### ★★ 计算题（2题 × 10分 = 20分）

**🥇 混淆矩阵 → Accuracy/Precision/Recall/F1（概率 95%）**

题目会给定样本真实标签和预测标签，要求：
1. 写出混淆矩阵（TP/FP/FN/TN）
2. 计算四个指标

→ 考试复习文档第6题就是这个套路，**几乎是必考题**。

**🥈 ROC曲线 + AUC计算（概率 85%）**

给 4-5 个样本的预测概率，要求：
1. 按概率排序
2. 逐阈值计算 TPR/FPR
3. 画出 ROC 曲线
4. 计算 AUC

→ 考试复习文档第7题就是完整流程，AUC 计算简单不容易错。

**🥉 FLD 计算题（概率 70%）**

给两类样本数据，要求：
1. 计算均值向量
2. 计算类内离散度矩阵 Sᴡ
3. 求最优投影向量 w = Sᴡ⁻¹(μ₁-μ₂)

→ 考试复习文档 Fisher 第6/7题就是标准套路。

**#4 PCA 计算题（概率 50%）**

给原始数据矩阵，要求：
1. 零均值化
2. 计算协方差矩阵
3. 特征值分解
4. 取主成分

→ 考试复习文档 PCA 第5题（草稿本图片）。

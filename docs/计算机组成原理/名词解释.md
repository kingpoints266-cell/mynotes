# 名词解释

## 第1章：计算机系统概述

**摩尔定律**
: 在价格不变的情况下，芯片集成度每18个月翻一番，极大地推动了计算机硬件的发展。

**冯·诺依曼体系结构**
: 现代计算机的基础架构，核心设计思想是"存储程序"和"程序控制"——将指令和数据以二进制形式存放在同一个存储器中，按顺序取出执行。

**五大基本部件**
: 运算器、控制器、存储器、输入设备、输出设备。其中运算器和控制器共同组成中央处理器（CPU）。

**哈佛体系结构**
: 与冯·诺依曼结构不同，将指令存储器和数据存储器分开存储，采用独立的两条总线，提高并行访问效率。

**机器语言**
: 计算机CPU能直接识别和执行的二进制代码语言，是唯一能被硬件直接执行的语言。

**汇编语言**
: 用助记符（如ADD、MOV）代替二进制机器码的低级语言，需经汇编程序翻译为机器语言。

**高级语言**
: 接近人类自然语言和数学公式的编程语言（如C、Java），需经编译或解释才能执行。

**汇编程序**
: 将汇编语言源程序翻译成机器语言目标程序的翻译程序。

**编译程序**
: 将高级语言源程序整体翻译成机器语言目标程序的翻译程序，翻译完成后可独立执行。

**解释程序**
: 边翻译边执行高级语言源程序的翻译程序，不产生独立的目标程序。

**软件与硬件的逻辑等价性**
: 任何由硬件实现的功能在逻辑上都可以用软件实现，反之亦然。区别在于成本、速度和灵活性。

**主频**
: CPU工作节拍的时钟频率，以MHz或GHz为单位，决定数字脉冲信号振荡的速度。

**时钟周期**
: 主频的倒数（T = 1/f），是CPU中最基本的时间单元，每个操作至少需要一个时钟周期。

**机器周期**
: 包含若干个时钟周期，是完成一个基本操作（如取指）所需的时间单位。

**CPI（Cycles Per Instruction）**
: 执行一条指令所需的平均时钟周期数。CPI = 总时钟周期数 / 总指令数。

**IPC（Instructions Per Cycle）**
: 每时钟周期执行的指令条数，IPC = 1/CPI，代表处理器的设计架构效率。

**MIPS（Million Instructions Per Second）**
: 每秒执行的百万条定点指令数。MIPS = 主频 / (CPI × 10⁶)。

**FLOPS / MFLOPS**
: 每秒执行的浮点操作次数 / 每秒百万次浮点操作数，衡量计算机的科学计算能力。

**CPU执行时间（tCPU）**
: 运行一个程序所花费的时间。tCPU = 指令总条数 × CPI × 时钟周期 = CPU时钟周期数 / 主频。

## 第2章：运算方法和运算器

**机器字长**
: CPU一次能并行处理的二进制位数，通常等于通用寄存器的位数。决定了计算机的运算精度和寻址能力。

**原码**
: 用最高位表示符号（0正1负），其余位表示数值绝对值的编码方式。存在+0和-0两个零。

**反码**
: 正数的反码与原码相同；负数的反码是符号位保持1，其余位按位取反。

**补码**
: 计算机中表示有符号数的标准方式。正数的补码与原码相同；负数的补码是反码末位加1。补码运算能将减法转换为加法。

**移码**
: 将补码的符号位取反得到，其无符号数值大小直接反映实际数值大小。专用于浮点数阶码，便于对阶比较。

**模**
: 定点整数运算的"循环范围"，对于n+1位字长的定点整数，模为2ⁿ⁺¹。补码的本质就是基于模运算。

**IEEE 754浮点数标准**
: IEEE制定的浮点数表示标准。32位单精度格式为：1位符号位(S) + 8位阶码(E，偏置127) + 23位尾数(M)。真值公式：X = (-1)ˢ × (1.M) × 2^(E-127)。

**规格化数**
: 浮点数中尾数最高位隐含为1的数（1.M形式），能充分利用尾数位数表示有效精度。

**非规格化数**
: 阶码全为0时的浮点数，隐藏位为0（0.M形式），用于表示非常接近0的数值。

**溢出**
: 运算结果超出了计算机所能表示的范围。两个正数相加得负数（上溢），或两个负数相加得正数（下溢）。

**单符号位法**
: 溢出检测方法之一：V = C_{n-1} ⊕ C_f，即最高数值位向符号位的进位与符号位向前的进位异或，结果为1则溢出。

**双符号位法（变形补码）**
: 使用两个符号位（正数00，负数11）进行运算检测溢出。01表示上溢，10表示下溢，V = 第一符号位 ⊕ 第二符号位。

**对阶**
: 浮点数加减运算的第一步，使两个操作数的阶码相等，小阶向大阶看齐，同时尾数右移相应位数。

**规格化处理**
: 浮点数运算后将尾数调整到规格化范围（|M| ∈ [0.5, 1)）。分为左规（尾数左移，阶码减1）和右规（尾数右移，阶码加1）。

**舍入处理**
: 浮点运算中对被移出的低位进行处理。常用0舍1入法（类似四舍五入）和恒舍法（直接截断）。

**阵列乘法器**
: 用大量加法器并行构成的硬件乘法电路。对于负数补码，会先去掉符号位，将数值位求反加1转为原码绝对值参与运算。

**不恢复余数除法**
: 一种除法算法：余数为负时商0，下一步加除数；余数为正时商1，下一步减除数。

**奇偶校验码**
: 最简单的检错码。通过添加校验位使数据中1的个数为奇数（奇校验）或偶数（偶校验），用于检测单比特错误。

**ALU（算术逻辑单元）**
: CPU中的核心运算部件，执行加、减、乘、除等算术运算及与、或、非、异或等逻辑运算。

## 第3章：存储系统

**多级存储体系**
: 为平衡容量、速度和成本三者矛盾而采用的层次化存储架构：寄存器 → Cache → 主存 → 辅存，越往上速度越快、容量越小、成本越高。

**SRAM（静态RAM）**
: 依靠双稳态触发器记忆信息，速度快、价格贵、不需刷新，通常用作Cache。

**DRAM（动态RAM）**
: 依靠电容上的电荷记忆信息，速度较慢但便宜、集成度高，需定期刷新，通常用作主存。属于破坏性读出，需读后重写。

**刷新**
: DRAM因电容漏电而必须定期补充电荷的操作。每次按行刷新，方式分为集中刷新（有死时间）、分散刷新（无死区但速度降低）和异步刷新（均匀分配刷新间隔）。

**ROM（只读存储器）**
: 非易失性存储器，断电不丢数据。包括掩膜ROM（不可改写）、PROM（一次性编程）、EPROM（紫外线擦除）、EEPROM（电可擦除按字节改）和Flash Memory（电可擦除按块改）。

**位扩展**
: 存储器扩展方式之一。增加存储字长，地址线和片选线并联，数据线分别接不同引脚。

**字扩展**
: 存储器扩展方式之一。增加存储单元数，数据线并联，高位地址线通过译码器产生片选信号。

**多模块交叉存储器**
: 采用多个主存模块并行工作来提高带宽。分为高位交叉（顺序方式，仅扩充容量）和低位交叉（轮流方式，可实现流水线并行访问）。

**交叉存取度（m）**
: 多模块交叉存储器中，满足T = mτ（存储周期等于m个总线传输周期）的模块数m。

**局部性原理**
: Cache设计的理论基础。包括时间局部性（刚访问过的数据可能再次被访问）和空间局部性（刚访问数据的邻近位置可能被访问）。

**Cache（高速缓冲存储器）**
: 位于CPU与主存之间的高速小容量存储器，利用局部性原理存放近期可能用到的数据，缓解CPU与主存的速度差距。

**全相联映射**
: Cache映射方式之一。主存块可放置到Cache的任意行，冲突最小但比较电路成本极高。地址结构：Tag + 块内地址。

**直接映射**
: Cache映射方式之一。主存块只能映射到Cache的唯一固定行（j = i mod 2ᶜ），硬件最简单但冲突最严重。地址结构：Tag + Line/Index + 块内地址。

**组相联映射**
: Cache映射方式的折中方案。Cache分组，主存块可放到固定组的任意行（组间直接映射，组内全相联）。地址结构：Tag + Set + 块内地址。

**LRU（近期最少使用法）**
: Cache替换算法，当Cache满时，淘汰最长时间没有被访问的那一块。

**FIFO（先进先出法）**
: Cache替换算法，当Cache满时，淘汰最早进入Cache的那一块。

**全写法（Write-Through）**
: 写策略之一。CPU写数据时同时写入Cache和主存，保证一致性但速度较慢。

**写回法（Write-Back）**
: 写策略之一。CPU只写Cache，当该块被替换出Cache时才写回主存。需要脏位标记被修改过的块。

**脏位（Dirty Bit）**
: 写回法Cache中标记某块是否被修改过的标志位。脏块在被替换时必须写回主存。

**虚拟存储器**
: 将"主存-辅存"抽象为一个统一大地址空间的技术，使程序员可使用比实际物理内存更大的地址空间。

**页式虚拟存储器**
: 将虚拟地址和物理地址空间都划分为固定大小的页，通过页表进行映射。优点是简单、页内碎片小。

**段式虚拟存储器**
: 按程序的逻辑模块划分段，每段长度可变。优点是共享和保护方便，缺点是有外部碎片。

**段页式虚拟存储器**
: 先分段再分页，结合两者优点，但地址变换需两次查表（段表+页表），开销较大。

**TLB（快表/Translation Lookaside Buffer）**
: 页表的高速缓存，存放最近使用的页表项，命中时可直接获得物理地址，避免访问主存中的页表。

**大端模式（Big-endian）**
: 多字节数据存储方式：最高有效字节（MSB）存放在低地址。

**小端模式（Little-endian）**
: 多字节数据存储方式：最低有效字节（LSB）存放在低地址。

**MAR（存储器地址寄存器）**
: 存放当前CPU访问的内存地址单元，其位数决定最大寻址范围。

**MDR（存储器数据寄存器）**
: 暂存由内存读出的信息或将要写入内存的信息。

**字节地址空间**
: CPU能够直接以字节为单位寻址访问的内存地址范围，大小 = 2ⁿ × 1 Byte（n为地址总线宽度）。

## 第4章：指令系统

**机器指令**
: CPU能直接识别和执行的二进制代码，由操作码和地址码两部分组成，规定计算机应执行什么操作以及操作数的位置。

**操作码（Opcode）**
: 指令中指明操作类型（如加、减、传送、跳转）的字段。

**地址码（Address）**
: 指令中指明操作数地址或操作结果存放位置的字段。

**零地址指令**
: 只有操作码无地址码的指令，如停机、空操作等，执行速度最快。

**一地址指令**
: 包含操作码和一个地址码的指令，如INC（加1）、NOT（取反）等。

**二地址指令**
: 包含操作码和两个地址码的指令，如ADD、MOV等，是最常见的指令格式。

**三地址指令**
: 包含操作码和三个地址码的指令，用于复杂的操作。

**寻址方式**
: 指令中给出操作数或操作数地址的方式，也就是确定本条指令的数据地址及下一条指令地址的方法。

**形式地址**
: 指令地址码字段中直接给出的值，不一定是操作数的真实地址。

**有效地址（EA）**
: 操作数在内存中的真实地址，由寻址方式和形式地址共同确定。

**立即寻址**
: 操作数直接包含在指令中，取指令即得操作数，速度最快，但操作数固定不可修改。

**直接寻址**
: 指令中直接给出操作数在内存中的有效地址，简单直观，但地址固定无法动态修改。

**间接寻址**
: 指令中给出的是存放操作数地址的内存单元地址，需两次访问内存（先取地址，再取数据），灵活但速度慢。

**寄存器寻址**
: 操作数存放在寄存器中，指令中给出寄存器编号，速度最快，但寄存器数量有限。

**寄存器间接寻址**
: 寄存器中存放的是操作数的地址，结合了寄存器速度和间接寻址的灵活性。

**基址寻址**
: 有效地址 = 基址寄存器(BR) + 位移量(Disp)。基址由系统控制，适合程序重定位和多道程序环境。

**变址寻址**
: 有效地址 = 变址寄存器(IX) + 位移量(Disp)。变址由用户/程序控制可变，适合数组遍历。

**相对寻址**
: 有效地址 = PC(当前值) + 位移量(Disp)。与程序位置无关，适合分支跳转和循环控制，程序可浮动。

**CISC（复杂指令集计算机）**
: 指令系统庞大、长度不固定、多周期执行，采用微程序控制为主。代表架构：x86（Intel/AMD）。

**RISC（精简指令集计算机）**
: 指令数量少、长度固定、单周期执行，采用硬布线控制，强调流水线和Load/Store架构。代表架构：ARM、MIPS、RISC-V。

**定长操作码**
: 所有指令的操作码位数相同，译码简单快速，但最多支持的指令条数受限。

**扩展操作码**
: 操作码位数可变，短操作码对应常用指令，长操作码对应不常用指令，更加灵活，可支持更多指令。

## 第5章：中央处理器

**CPU（中央处理器）**
: 计算机的核心部件，由运算器和控制器组成，负责解释和执行指令，控制整个计算机系统的运行。

**数据通路（Datapath）**
: 处理器中数据流动的路径，包括寄存器、运算单元、总线等部件。数据通路的设计直接影响处理器性能和实现复杂度。

**单周期数据通路**
: 每条指令在一个时钟周期内完成执行，时钟周期必须足够长以容纳最复杂指令，硬件利用率较低。

**多周期数据通路**
: 指令执行分解为多个时钟周期，不同指令需要不同数量的周期，通过复用硬件部件减少资源消耗。

**流水线（Pipeline）**
: 将指令执行分为多个阶段，使多条指令能同时处于不同执行阶段，从而提高指令吞吐率的技术。

**流水线寄存器**
: 流水线各阶段之间设置的寄存器，用于暂存阶段间的数据和控制信号（如IF/ID、ID/EX、EX/MEM、MEM/WB）。

**IF（取指阶段）**
: 从指令存储器取出指令，PC更新为下一条指令地址。

**ID（译码阶段）**
: 解析操作码和寄存器字段，读取寄存器堆中的操作数，产生控制信号。

**EX（执行阶段）**
: ALU执行算术/逻辑运算，计算访存有效地址或分支目标地址，判断分支条件。

**MEM（访存阶段）**
: 访问数据存储器进行读/写操作，分支成立时更新PC。

**WB（写回阶段）**
: 将运算结果或访存结果写回寄存器堆。

**吞吐率（Throughput）**
: 流水线性能指标：单位时间内完成的指令数量。理想情况下k级流水线的吞吐率是非流水线的k倍。

**加速比（Speedup）**
: 流水线处理器与非流水线处理器执行相同数量指令的时间比值，理想最大加速比为流水线级数k。

**结构冒险（Structural Hazard）**
: 流水线冒险类型：硬件资源不足以支持所有指令组合同时执行，如同一时刻两条指令都需要访问同一存储器。

**数据冒险（Data Hazard）**
: 流水线冒险类型：指令间存在数据依赖关系，后一条指令需要前一条指令的结果但结果尚未计算完成。

**RAW（读后写）**
: 真实数据相关：后一条指令需要读取前一条指令写入的数据，是最常见也是必须处理的冒险。

**WAR（写后读）**
: 反相关：后一条指令需要写入前一条指令要读取的寄存器，在按序流水线中不会发生。

**WAW（写后写）**
: 输出相关：两条指令都向同一寄存器写入数据，在按序流水线中不会发生。

**控制冒险（Control Hazard）**
: 流水线冒险类型：分支指令和跳转指令造成的，在分支条件判断完成之前后续指令已进入流水线。

**停顿（Stall）**
: 插入气泡使后续指令暂停执行，等待冒险条件解决，实现简单但会降低流水线效率。

**转发（Forwarding / Bypassing）**
: 将计算结果直接从流水线的一个阶段转发到另一个阶段，无需等待写回寄存器堆，可避免大部分数据冒险。

**加载互锁（Load Interlock）**
: 加载指令的结果在MEM阶段才能得到，即使转发也无法解决，需插入停顿等待加载完成。

**分支预测（Branch Prediction）**
: 解决控制冒险的技术，预测分支是否发生及目标地址。包括静态预测和动态预测（1位/2位饱和计数器、全局/局部历史预测）。

**延迟分支（Delayed Branch）**
: 将分支指令与延迟槽结合，延迟槽中的指令无论分支是否发生都会执行，充分利用流水线。

**超标量（Superscalar）**
: 每个时钟周期发射多条指令到流水线，需要指令并行性检测和多个执行单元的协调。

**超长指令字（VLIW）**
: 将多条指令打包成一个长指令字，由编译器负责指令调度和并行性分析，硬件简单。

**乱序执行（Out-of-Order Execution）**
: 允许指令不按程序顺序执行，只要不违反数据依赖，需要寄存器重命名和重排序缓冲（ROB）。

**微操作（Micro-operation）**
: 处理器中最基本的不可分割的操作，如寄存器传输、ALU操作、访存操作、转移操作等。

**微命令**
: 控制部件通过控制线向执行部件发出的一种最低层控制信号，直接打开或关闭某个控制门。微命令是微操作的控制信号。

**微指令**
: 微程序中的一条指令，由控制字段（产生控制信号）和下址字段（指明下一条微指令地址）组成。若干条微指令构成一段微程序。

**微程序**
: 实现一条机器指令功能所需的一组微指令序列，存储在控制存储器中。

**控制存储器（Control Memory）**
: CPU内部存放微程序的专属存储器，微指令全部固化在其中。

**硬布线控制（Hardwired Control）**
: 采用组合逻辑电路直接从操作码和状态产生控制信号，速度快、设计复杂、不易修改，适合RISC处理器。

**微程序控制（Microprogrammed Control）**
: 将控制信号序列存储在控制存储器中，通过微指令的解释执行产生控制信号，规整性好、易修改，适合CISC处理器。

**水平型微指令**
: 微指令格式之一：每一位对应一个控制信号，并行控制能力强、效率高但微指令字长。

**垂直型微指令**
: 微指令格式之一：编码表示微操作，字长短但需译码、执行速度较慢。

## 第6章：总线系统

**总线（Bus）**
: 计算机系统各部件之间传输数据、地址和控制信息的共享公共通道。多个设备通过共享路径传输数据，避免了全互连的复杂性。

**主设备（Master）**
: 能发起总线请求并控制总线活动的设备，通常是CPU或DMA控制器。

**从设备（Slave）**
: 响应主设备请求，被动接收或发送数据的设备，如内存、显示器等。

**系统总线**
: 连接CPU、主存等主要部件的总线，传送数据、地址和控制信息。

**并行总线**
: 同时传送多位数据的总线，传输速度快但占用较多引脚、信号同步困难，适合短距离传输。

**串行总线**
: 逐位传送数据的总线，引脚少、抗干扰能力强、适合长距离传输。现代高速总线（如PCIe、USB）多采用串行方式。

**总线宽度**
: 总线上能同时传输的数据位数，通常与数据总线位数相同（8位、16位、32位、64位等）。

**总线频率**
: 总线时钟信号的频率，通常以MHz或GHz为单位。

**总线带宽**
: 总线传输速率的理论最大值。计算：带宽 = 总线宽度 × 总线频率 / 8。

**总线仲裁（Bus Arbitration）**
: 当多个设备同时请求使用总线时，决定谁先使用的机制。分为集中式仲裁和分布式仲裁。

**链式查询方式（菊花链仲裁）**
: 集中式仲裁方式：所有设备通过共享请求线向仲裁器发出请求，授权线依次传递。离仲裁器越近优先级越高，结构简单但优先级固定。

**计数器查询方式**
: 集中式仲裁方式：仲裁器用计数器依次查询各设备是否有请求，优先级可通过设置计数器初始值灵活调整。

**独立请求方式**
: 集中式仲裁方式：每个设备都有独立的请求线和授权线，响应最快、优先级算法灵活，但控制线数量多。

**同步总线**
: 使用统一时钟信号同步所有操作的总线，简单快速但速度受限于最慢设备。

**异步总线**
: 没有统一时钟，采用握手协议协调通信的总线。适应不同速度设备，但协议开销大。

**半同步总线**
: 结合同步和异步特点，以时钟为基础但允许慢速设备通过等待信号插入等待周期。

**分离式总线**
: 将一次总线传输分为两个独立阶段（如读操作先发地址再等从设备回传数据），各阶段间总线可被其他设备使用，利用率高。

**ISA总线**
: Industry Standard Architecture，早期PC的8位/16位标准总线，带宽约5~10MB/s，已被PCI取代。

**PCI总线**
: Peripheral Component Interconnect，32位/64位总线，33/66MHz，支持即插即用，独立于处理器架构。

**PCIe（PCI Express）**
: 串行点对点连接总线，采用通道（Lane）概念（x1/x4/x8/x16），每通道全双工通信，现代计算机的主流总线。

**USB（Universal Serial Bus）**
: 通用串行总线，支持热插拔和即插即用，星形拓扑，是PC外设的事实标准接口。

## 第7章：外围设备

**外围设备（Peripheral Equipment）**
: 计算机系统中负责与外部世界进行数据交互的设备，包括输入设备、输出设备和外存储器三类。

**电阻式触摸屏**
: 两层透明导电薄膜组成，触摸时接触产生电信号确定位置。成本低、可用任意物体触摸，但透光率低。

**电容式触摸屏**
: 利用人体电场产生的电容变化检测触摸位置。透光率高、支持多点触控，但需要导体触摸。

**CRT显示器（阴极射线管）**
: 使用电子枪发射电子束轰击荧光屏发光的显示设备，色彩好、响应快，但体积大、功耗高。

**LCD显示器（液晶显示器）**
: 利用液晶分子在电场作用下的排列变化控制光线通过的显示设备，轻薄节能。

**OLED显示器**
: 采用有机发光材料，每个像素自发光的显示设备。不需要背光源，更薄、对比度更高、视角更大。

**分辨率**
: 显示器屏幕上像素的数量，如1920×1080、3840×2160(4K)，分辨率越高画面越精细。

**刷新率**
: 显示器每秒钟画面更新的次数，以Hz为单位（如60Hz、144Hz），刷新率越高画面越流畅。

**响应时间**
: 显示器像素从一种颜色变换到另一种颜色所需的时间，越小动态画面拖影越少。

**GPU（图形处理器）**
: 专门处理图形运算的处理器，拥有大量并行计算单元，负责图形渲染流水线（顶点处理、光栅化、片元处理等）。

**针式打印机**
: 使用打印针击打色带将墨水转移到纸上，噪音大、精度低，但可打印多层复写纸，用于发票、收据等。

**喷墨打印机**
: 将墨水微粒喷射到纸上形成图像，彩色效果好、噪音低、相对便宜，适合家庭使用。

**激光打印机**
: 使用激光束在感光鼓上形成静电潜像吸附碳粉转印定影，速度快、质量高、耗材成本低，适合办公。

**HDD（硬盘驱动器）**
: 使用磁盘片和磁头进行磁记录存储的外存储设备，容量大、成本低，但存在机械部件、速度较慢。

**磁道（Track）**
: 磁盘盘片表面的同心圆轨道，数据分布在不同磁道上。

**扇区（Sector）**
: 每个磁道上划分的最小寻址单元，通常为512字节。

**平均寻道时间**
: 磁头移动到指定磁道所需的平均时间，通常为几毫秒，是磁盘访问总时间的主要组成之一。

**平均等待时间（平均旋转延迟）**
: 磁头到达正确磁道后，等待数据所在扇区旋转到磁头下方的平均时间，取转半圈的时间 = 1/(2r)。

**数据传送时间**
: 磁头对准扇区后，读写数据所需的时间。数据传送时间 = 数据量大小 / 数据传输率。

**数据传输率**
: 磁盘单位时间内读写的数据量。数据传输率 = 转速(r/s) × 每道信息量。

**位密度**
: 磁道单位长度上记录的二进制位数。最内圈直径最小、周长最短，位密度最高；最外圈直径最大，位密度最低。

**SSD（固态硬盘）**
: 使用NAND Flash闪存芯片存储数据的存储设备，无机械部件，速度快、功耗低、抗震，但成本高、有写入次数限制。

**SLC / MLC / TLC / QLC**
: 每个闪存单元分别存储1/2/3/4位数据，SLC速度最快寿命最长但成本最高，QLC反之。

**TRIM**
: 操作系统告知SSD哪些数据已删除可以擦除的命令，用于维护SSD性能。

**磨损均衡（Wear Leveling）**
: SSD控制器将写入操作分散到不同区块，避免某些区块过度磨损，延长整体使用寿命。

**垃圾回收（Garbage Collection）**
: SSD控制器在后台整理和回收已删除数据占用的闪存空间。

**CD / DVD / 蓝光光盘**
: 不同代的光盘存储介质。CD约700MB（红外激光），DVD单面4.7GB（红光），蓝光25GB起（蓝光），激光波长越短容量越大。

## 第8章：输入输出系统

**I/O接口（I/O控制器）**
: 介于CPU和I/O设备之间的硬件电路，负责数据缓冲、格式转换、设备选择、状态监视、控制与定时、中断处理等功能。

**程序直接控制方式（程序查询方式）**
: 最简单的I/O控制方式。CPU不断轮询设备状态寄存器直到设备就绪再进行数据读写。CPU效率极低，适用于低速简单设备。

**程序中断方式**
: I/O设备在完成操作或发生异常时主动向CPU发送中断请求信号，CPU暂停当前任务处理中断后再返回。提高了CPU效率，是应用最广泛的I/O方式。

**DMA方式（直接内存访问）**
: 由DMA控制器代替CPU管理数据在I/O设备和内存之间的直接传输，CPU只在传输开始和结束时参与。适合高速大批量传输。

**通道方式**
: 专门处理I/O的处理器，有自己的指令系统，可独立执行通道程序完成复杂I/O控制。CPU介入最少，适用大型高性能系统。

**中断请求**
: I/O设备向CPU发出的请求处理信号，CPU在每条指令执行结束后检查是否有中断请求。

**中断响应**
: CPU检测到中断请求且允许响应时，进入中断处理流程。

**保护现场**
: CPU在进入中断处理前保存当前程序的运行状态（PC、寄存器等），以便中断处理完成后能正确返回。

**恢复现场**
: 中断处理完成后，恢复之前保存的程序状态。

**中断返回**
: CPU执行中断返回指令，回到原程序被中断的位置继续执行。

**中断优先级**
: 当多个中断同时发生时，CPU根据各中断源的优先级决定处理顺序。高优先级中断可打断低优先级中断（中断嵌套）。

**中断嵌套**
: 高优先级中断可以暂停正在执行的低优先级中断处理程序，等处理完高优先级中断后再恢复低优先级中断处理。

**DMA控制器**
: 负责管理DMA传输的专用硬件，包含地址寄存器、计数寄存器、控制逻辑等。可代替CPU进行内存与设备间的数据传送。

**停止CPU访问（DMA传输方式）**
: DMA工作时完全占用总线，CPU停止访问内存。传输效率高但CPU无法执行其他任务。

**周期挪用（DMA传输方式）**
: DMA利用CPU不访问内存的空闲周期进行传输，不需要完全停止CPU，但可能引起单周期延迟。

**DMA与CPU交替访问**
: 将内存时间分成两部分，一部分供CPU使用，一部分供DMA使用。无需等待但控制复杂。

**字节多路通道**
: 为多个低速设备服务，以字节为单位交叉传输数据。

**选择通道**
: 为单台高速设备服务，独占通道直到传输完成。

**数组多路通道**
: 为多台高速设备服务，数据传输以块为单位交叉进行。

**数据寄存器**
: I/O接口中暂存输入或输出数据的寄存器，缓冲CPU与设备间的速度差异。

**状态寄存器**
: I/O接口中反映设备当前状态的寄存器，包含忙位（Busy）、就绪位（Ready）、错误位（Error）等。

**控制寄存器**
: I/O接口中CPU写入控制命令的寄存器，用于设置设备的工作模式。

**统一编址（内存映射I/O）**
: 将I/O设备寄存器映射到内存地址空间中，CPU使用访问内存的指令访问I/O设备，不需要专门的I/O指令。

**独立编址**
: I/O设备有独立的地址空间，与内存地址空间分开。CPU使用专门的I/O指令（如IN、OUT）访问设备，不占用内存地址空间。

**设备驱动程序（Device Driver）**
: 操作系统与硬件设备之间的软件接口，向上提供统一的设备抽象，向下控制设备硬件完成具体操作。

**即插即用（Plug and Play）**
: 设备插入后系统自动识别并加载相应驱动程序的技术，无需手动配置。

**吞吐量（Throughput）**
: I/O系统性能指标：单位时间内完成的数据传输量，通常以MB/s或GB/s表示。

**中断饱和时间**
: CPU完全被中断服务程序和中断开销所占满、没有任何空闲时间执行主程序的状态。当所有设备中断开销之和等于可用时间时即达到饱和。
